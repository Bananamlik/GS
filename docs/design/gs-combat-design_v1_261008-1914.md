# GS Action 전투 설계: 카메라·조준·이동·가독성·빌드 축 (v1 초안)

작성: 2026-10-08 KST. 짝 문서: `gs-run-skeleton_v1_261006-2213.md`(런 구조). 이 문서는 **전투 한 판 안**을 다룬다.
수치는 전부 초안이다. 플레이로 확인하지 않은 것은 **UNVERIFIED**. §10의 결정이 나기 전에는 코드로 옮기지 않는다.

## 1. 왜 필요한가

- 런 구조(지도·보상·상점·해금)는 설계와 구현이 있다. 전투 한 판의 조작감·화면 규칙은 문서가 없고 코드에 흩어져 있다.
- VFX 위치 점검(`docs/evidence/gs-vfx-anchor-audit_v2_261008-1811.md`)에서 "과대" 10개를 판정하지 못했다. "효과가 화면을 얼마나 가려도 되는가"라는 기준이 없어서다.
- S6(지역별 적·보스)는 적의 역할과 보스 패턴 규칙이 먼저 있어야 한다.
- 방침: 평점 3 이상 효과만 쓴다(현재 243개). 더 높은 품질의 효과가 추가될 예정이므로 빌드 축(§8)은 그 목록을 받은 뒤 확정한다.

비어 있는 것: 카메라 거리 조절, 큰 효과가 화면을 가릴 때 규칙, 조준 보조, 터치에서 범위 스킬 놓는 규칙, 내 효과와 적 공격의 시각 구분 규칙, 피격 방향 표시, 적 역할 체계, 보스 패턴 규칙, 스킬 간 시너지 축.

## 3. 큰 틀: 전투 한 판의 목표 경험

**"넓은 원형 경기장에서, 직접 조준해 화려한 기술을 쏘고, 적의 예고를 읽고 피한다."** 3인칭 조준 액션이다.

세 가지 원칙으로 모든 세부 결정을 가른다.

| 원칙 | 뜻 | 어기면 생기는 일 |
|---|---|---|
| P1. 읽힌다 | 0.5초 안에 "어디가 위험한지, 내 기술이 어디에 떨어지는지"가 보인다 | 화려한 효과에 적 예고가 묻혀 억울하게 맞는다 |
| P2. 조준은 내 것 | 방향과 지점은 플레이어가 정한다. 보조는 손이 불편한 입력(터치)을 메우는 정도만 | 자동으로 맞으면 243개 기술의 형태 차이가 의미 없어진다 |
| P3. 효과는 보상 | 큰 효과는 쿨이 길고 드물게, 작은 효과는 자주. 크기와 빈도가 반비례 | 화면이 항상 꽉 차서 궁극기가 특별하지 않다 |

한 전투 길이는 런 설계대로 수십 초~2분. 한 전투 안의 흐름은 "접근(적 위치 파악) → 교전(기술 순환, 회피) → 정리(남은 적)"의 3박자다.

## 4. 카메라

### 4.1 기본 시점

- 3인칭을 기본으로 유지한다. 1인칭은 선택으로 남긴다(큰 효과가 눈앞에서 터져 P1에 불리하다).
- 현재 거리 6.4단위(1.3 m)는 어깨 뒤 근접 시점이다. 영웅이 화면을 크게 가리고, 발밑 장판과 뒤쪽 적이 안 보인다.

| 항목 | 현재 | 초안 | 이유 |
|---|---|---|---|
| 거리 | 6.4 고정 | 기본 11, 설정으로 8~16 | 반경 11~15짜리 범위 스킬과 발밑 예고가 한 화면에 들어오게 |
| 높이 | 눈높이 + 2.1 | 눈높이 + 3.5, 살짝 내려봄 | 바닥 예고 표시가 P1의 핵심이라 바닥이 더 보여야 함 |
| 어깨 치우침 | 없음(정중앙) | 오른쪽 1.6 | 조준선이 영웅 몸에 가리지 않게 |
| 시야각 | 60° | PC 60°, 세로 화면 72° | 세로 화면은 좌우가 좁아 옆의 적이 안 보임 |
| 벽 충돌 | 즉시 당김, 천천히 복귀 | 유지 | 이미 동작함 |

### 4.2 상황별 카메라

| 상황 | 동작 | 길이 |
|---|---|---|
| 궁극기 시전 | 거리 +3, 히트스톱과 함께 짧게 멈춤. 조작은 끊지 않음 | 0.4초 |
| 보스 등장·페이즈 전환 | 보스 쪽으로 시선 유도(자동 회전 아님, 화면 가장자리 표시 + 느린 줌) | 1.2초, 건너뛰기 가능 |
| 피격 | 흔들림(현행) + 맞은 방향 화면 가장자리 표시(신규) | 0.3초 |
| 마지막 적 처치 | 느린 화면 0.25초 | — |

카메라가 플레이어의 조준을 강제로 돌리는 연출은 넣지 않는다(P2).

### 4.3 효과가 화면을 가릴 때 (P1)

- **화면 점유 한도**: 내 효과 하나가 화면의 40%를 넘게 덮는 시간은 0.6초까지. 넘으면 그 효과의 불투명도를 낮춘다. 궁극기는 60%·1.2초까지.
- **카메라 근접 감쇠**: 카메라에서 4단위 안의 효과 조각은 투명하게 한다(파편·연기가 렌즈를 덮는 경우).
- **적 예고 우선**: 적 예고 표시는 내 효과 위에 그린다(깊이 무시, 밝기 고정).
- 판정표의 "과대" 10개(`FX-21`, `INT-03`, `INT-08-P`, `FX-10-C`, `GS-digital`, `CH:emille`, 투사체 고리 4종)는 이 한도로 다시 잰다. 효과를 고치지 않고 규칙으로 처리하는 것이 목표다.

## 5. 조준과 대상

### 5.1 PC (마우스)

- 수동 조준 유지. 조준 보조 없음.
- 범위 스킬(원형·영역·설치): 조준선이 바닥과 만나는 점에 놓는다. 사거리 밖이면 사거리 끝에 놓는다. 준비 동작 동안 바닥에 예상 범위를 표시한다(현행 windup 표시 확장).
- 빔·투사체: 조준선 방향. 높이는 가슴 높이에서 나가 표적 몸 높이로.

### 5.2 터치

터치는 오른손이 시점과 버튼을 같이 맡아 조준 정밀도가 떨어진다. 보조를 넣되 P2를 지키는 범위로 한다.

| 보조 | 내용 | 초안 수치 |
|---|---|---|
| 방향 끌림 | 버튼을 누른 순간, 조준선 좌우 원뿔 안에 적이 있으면 가장 가까운 적 쪽으로 시전 방향만 보정. 시점은 돌리지 않음 | 원뿔 ±12°, 사거리 안 |
| 지점 끌림 | 범위 스킬의 지점이 적에게서 가까우면 그 적 발밑으로 | 반경의 60% 안 |
| 길게 눌러 조준 | 스킬 버튼을 누른 채 끌면 지점·방향을 직접 정하고 떼면 시전 | 누름 0.18초 이상 |

- 보조는 설정에서 끌 수 있다. PC에서는 기본 꺼짐.
- 대상 고정(락온)은 넣지 않는다. 적이 여럿인 전투에서 대상 전환 조작이 부담이고, 범위 스킬 위주인 이 게임과 맞지 않는다.

## 6. 이동·회피·시전

| 항목 | 현재 | 초안 |
|---|---|---|
| 회피 | 0.35초, 무적 0.38초, 쿨 있음 | 유지. 무적이 이동보다 0.03초 길어 끝에 맞지 않는 점도 유지 |
| 준비 동작 중 회피 | 불가 | **회피로 취소 가능**(쿨·자원은 돌려주지 않음). 예고를 보고도 못 피하는 억울함을 없앰. 궁극기는 취소 불가 |
| 시전 중 이동 | 스킬마다 다름(`stationary`) | 규칙으로 통일: 기본·소형 = 이동하며 시전, 대형·궁극 = 제자리 |
| 입력 버퍼 | 있음 | 유지. 창 0.25초로 명시 |
| 피격 경직 | 넉백 값만 있음 | 일반 공격은 경직 없음, 정예·보스의 큰 공격만 0.3초 경직. 연속 경직 방지 1초 |
| 점프·높이 | 없음 | 넣지 않음. 평지 조준 액션으로 고정(카메라·판정·효과 배치가 전부 평지 전제) |

## 7. 가독성 규칙 (P1)

| 규칙 | 내용 |
|---|---|
| 색 역할 | 적 예고 = 붉은 계열 고정. 아군 회복·보호 = 녹색·청록. 내 공격 효과는 속성 색을 쓰되 **바닥 표시에 순수 빨강을 쓰지 않는다** |
| 예고 문법 | 원 = 그 자리, 직선 띠 = 관통, 부채꼴 = 근접 휘두름. 채워지는 속도 = 남은 시간. 모든 적·보스가 같은 문법 |
| 최소 예고 시간 | 일반 0.4초, 원거리 0.8초, 정예·보스 큰 공격 1.0초 이상(난이도 단계가 올라도 0.35초 아래로는 안 줄임) |
| 밝기 상한 | 내 효과의 흰색 포화 면적은 화면 25%·0.3초까지. 판정표의 `GS-digital`(흰 면이 적을 가림) 같은 경우가 대상 |
| 적 윤곽 | 내 효과 뒤에 있는 적은 윤곽선을 유지 |
| 피격 방향 | 화면 가장자리에 방향 표시 0.3초 |
| 화면 밖 위협 | 예고 중인 화면 밖 공격은 가장자리에 화살표(현행 `#gaThreats` 확장) |

## 8. 적 역할, 보스, 빌드 축

### 8.1 적 역할 (S6의 입력)

| 역할 | 하는 일 | 기존 적 | 플레이어가 배우는 것 |
|---|---|---|---|
| 돌격 | 붙어서 때림 | 잡귀, 엘리트 잡귀 | 거리 유지, 범위 스킬 |
| 저격 | 멀리서 직선 공격 | 원귀궁 | 예고 띠 읽기, 옆걸음 |
| 장판 | 바닥을 막음 | 역귀 | 위치 선정, 이동 경로 |
| 포격 | 예고 원을 떨어뜨림 | 술사 | 회피 타이밍 |
| 방해(신규 후보) | 느려짐·끌어당김 | 없음 | 우선순위 처치 |
| 보호(신규 후보) | 주변 적에게 보호막 | 없음 | 대상 선택, 관통 스킬 |

지역별 구성(런 설계 §7에 맞춤): 지역 1 = 돌격 + 저격, 지역 2 = 장판 + 포격 중심, 지역 3 = 전부 + 신규 역할.

### 8.2 보스 문법

- 페이즈 3개. 페이즈마다 새 패턴 1개 추가, 앞 패턴은 유지.
- 패턴 1개 = 예고(§7 문법) → 판정 → 빈틈(공격 기회 1.5~2.5초). 빈틈 없는 패턴은 만들지 않는다.
- 한 번에 겹치는 패턴은 2개까지.
- 지역 보스 3종(강화 잡귀 / 강화 술사 / 두억시니)은 이 문법으로 다시 적는다. `GA_SIM` 규칙은 바꾸지 않고 데이터로 넣는다.

### 8.3 빌드 축 (초안, 새 효과 목록을 받은 뒤 확정)

스킬 243개를 "고를 이유"가 생기게 묶는 축이다.

| 축 | 값 | 출처 |
|---|---|---|
| 형태 | 투사체 / 빔 / 지점 / 영역 / 설치물 / 자기 | 이미 분류됨(`formOf`) |
| 속성 | 뇌전·화염·빙결·물·대지·빛·암흑·기계 등 | 주제 상태이상 표(`GA_SKILL_THEME`)와 이름 |
| 상태이상 | 둔화·화상·감전·저주 등 | 스킬 표의 상태이상 열 |

- 시너지는 "같은 속성 N개"가 아니라 **형태 조합**으로 만든다. 예: 영역으로 묶고 → 지점으로 터뜨림, 설치물이 빔을 굴절. 형태 차이가 화면에서 바로 보여 P1·P3과 맞는다.
- 패시브 12종은 수치형뿐이다. 형태 조건부 패시브(예: "영역 안의 적에게 지점 피해 +25%")를 추가 후보로 둔다.
- 이 절은 방향만 적는다. 표와 수치는 v2에서.
