## 0. 한 줄

**예고를 읽고 틈을 만들어, 모은 스킬 조합을 터뜨린다.**

## 1. 무엇을 요구하나 (플레이 방식)

채택: **A. 읽고 피하고 꽂기.**

| 요구 | 뜻 | 요구하지 않는 것 |
|---|---|---|
| 읽기 | 적 예고(원·띠·부채꼴, 채워지는 속도 = 남은 시간)를 보고 다음 1~2초를 안다 | 암기해야 하는 숨은 패턴 |
| 피하기 | 걷기 또는 회피로 예고 밖으로 나간다. 준비 동작도 회피로 끊는다(C4) | 프레임 단위 입력, 콤보 커맨드 |
| 꽂기 | 적의 빈틈(패턴 뒤 1.5~2.5초)에 큰 스킬을 넣는다 | 아무 때나 난사해도 되는 전투 |

버린 안: B 쓸어담기(화면 가림·발열과 충돌), C 정밀 조작(터치에 불리).

규칙으로 옮기면:
- 큰 스킬일수록 준비가 길다 → 틈 없이 쓰면 맞는다. 화려한 효과 = 틈을 만든 보상.
- 모든 적 공격은 예고가 있다. 예고 없는 피해는 만들지 않는다(상태이상 지속 피해 제외).
- 빈틈 없는 패턴은 만들지 않는다(전투 설계 §8.2).

## 2. 무엇이 재미인가

| 길이 | 재미 | 받치는 것 | 현재 |
|---|---|---|---|
| 순간(초) | 틈에 큰 스킬이 제대로 꽂힘 | 예고 가독성 C5, 회피 취소 C4, 화면 가림 한도 C6 | C4 완료, C5 진행, C6 남음 |
| 한 판(15~20분) | 스킬 조합이 맞물림 | 형태 조합 시너지(전투 설계 §8.3, D9), 보상 3택 | 보상·패시브 있음. 조합 규칙 없음 |
| 판 사이 | 새 스킬·영웅으로 다른 조합 시도 | 해금(S7), 도감 | 해금 있음. 도감 없음 |

가장 약한 곳 = "한 판" 줄. 스킬 243개가 보기로만 구분되고 고를 이유가 약하다 → 빌드 축을 새 효과 반입 전으로 앞당긴다(§5).

## 4. 이 문서로 판단하는 법

새 기능·스킬·적을 넣을 때 세 가지를 묻는다. 하나도 해당 없으면 넣지 않는다.
1. 읽기·피하기·꽂기 중 무엇을 더 분명하게 하나?
2. 순간·한 판·판 사이 중 어느 재미를 키우나?
3. 어느 목표로 가는 길에 놓이나?

적용 예:
- 화면을 덮는 효과 → 읽기를 해침 → 화면 점유 한도(C6) 대상.
- 자동 조준·락온 → 꽂기의 판단을 없앰 → 넣지 않음(D2·D5 유지). 터치 조준 보조(C3)는 입력 오차 보정까지만.
- 새 맵 → 목표(무대 확장)에 해당. 무대 묶음(`STAGES`)에 적 구성·보스를 함께 넣는다.
