## v53 → v54 변경 (줄 단위, 앵커 일치 1회씩 assert)

1. `three.min.js`(r128 UMD, cdnjs) → importmap `three@0.186.1`(jsdelivr) + 모듈 로더.
   - 본문은 sloppy 전역 스크립트라 모듈로 못 바꿈 (`const`/`function` 전역을 `page.evaluate`·외부가 참조).
   - 로더가 `THREE`를 `window`에 얹고 `<script type="text/plain" id="gsMain">` 내용을 클래식 `<script>`로 주입.
   - CDN 실패 시 기존과 같은 안내 문구.
2. `THREE.ColorManagement.enabled = false` + `renderer.outputColorSpace = LinearSRGBColorSpace`.
   - r128 색 경로(입력 변환 없음, Linear 출력) 유지. 본문 셰이더 `enc()`(수동 sRGB)가 그대로 맞음.
3. `.encoding = sRGBEncoding` 2곳 → `.colorSpace = SRGBColorSpace`. 주석 1곳 갱신.
4. 조명 4개(Hemisphere 1 · Directional 3) 세기 ×π. r128 레거시 조명은 내부 ×π였음.
5. **v53 기존 버그 수정**: `FAE_VS`·`FAERG_VS`가 `gsCurve()`를 호출하는데 `_SAG_GLSL` 접두가 없어 vertex shader 컴파일 실패 (`fae` 헤드). 접두 2줄 추가. Bug dead.
6. 제목·브랜드 문구 v53 → v54.

변경 안 함: 셰이더 본문, uniform, 지오메트리, 헤드 수치. 50줄 diff.
